# 💳 Financial Fraud Detection using SQL

SQL-based financial transaction analysis to detect suspicious and fraudulent patterns using subqueries, aggregation, and filtering techniques.

---

## 📊 Project Overview

This project analyzes financial transaction data to identify fraud patterns, high-value transactions, and unusual customer behavior using SQL queries.

It simulates real-world banking and fintech fraud detection scenarios using structured data analysis techniques.

---

## 🔍 Key Concepts Used

- Subqueries  
- Aggregate Functions (MAX, AVG, COUNT)  
- GROUP BY & HAVING  
- Filtering using IN, NOT IN, ANY, ALL  
- Pattern-based anomaly detection  

---

## 📌 Key Queries Implemented

- Highest Transaction Detection  
- Lowest Transaction Detection  
- Fraud Transaction Analysis  
- Customers Above Average Spending  
- Same Merchant Pattern Analysis  
- Cities with High Transaction Volume  
- Customers Not Involved in Fraud  
- Duplicate Transaction Detection  

---

## 📊 Key Insights

- Fraud transactions are often high-value and unusual  
- Certain merchants appear frequently in fraud cases  
- Customer spending patterns help identify anomalies  
- City-wise clustering shows risk concentration  
- SQL can effectively simulate fraud detection systems
